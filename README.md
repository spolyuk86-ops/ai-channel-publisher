# Автопублікація постів у @AI_NA_KAGDIY_DEN

Публікує пост із `schedule.json` щодня о 8:00, 11:00 та 15:00 (за Києвом)
через GitHub Actions — безкоштовно, без власного сервера.

## Налаштування (один раз)

1. **Додайте бота адміністратором каналу**
   Telegram → ваш канал → «Адміністратори» → «Додати адміністратора» →
   знайдіть свого бота → увімкніть право **«Публікація повідомлень»**.
   Без цього бот не зможе постити, навіть маючи правильний токен.

2. **Створіть репозиторій на GitHub**
   Завантажте туди всі файли з цієї папки (publish.py, schedule.json,
   .github/workflows/publish.yml, README.md), зберігаючи структуру папок.

3. **Додайте секрети репозиторію**
   У репозиторії: Settings → Secrets and variables → Actions → New repository secret.
   Додайте два секрети:
   - `TELEGRAM_BOT_TOKEN` — токен вашого бота від @BotFather
   - `CHANNEL_USERNAME` — `@AI_NA_KAGDIY_DEN`

   Токен ніде більше в проєкті не зберігається — тільки в цьому захищеному
   сховищі GitHub, і скрипт бере його звідти під час запуску.

4. **Перевірте вручну**
   Вкладка Actions → workflow «Publish scheduled post» → Run workflow
   (кнопка «Run workflow» з `workflow_dispatch`). Перевірте, що пост
   з'явився в каналі.

## Як це працює

- `schedule.json` — тексти постів на кожен день тижня і кожен слот часу.
- `publish.py` — визначає поточний день тижня і час (UTC), бере відповідний
  пост зі schedule.json і надсилає його через Telegram Bot API.
- `.github/workflows/publish.yml` — запускає скрипт автоматично тричі на день.

## Важливо

- GitHub Actions працює в UTC. Cron у workflow вже перерахований під
  літній час Києва (UTC+3). Коли Україна перейде на зимовий час (UTC+2,
  зазвичай останні вихідні жовтня), потрібно буде зсунути час у cron на
  1 годину вперед (05:00→06:00, 08:00→09:00, 12:00→13:00 UTC) — просто
  напишіть мені, і я поправлю файл.
- GitHub Actions може запускати завдання з невеликою затримкою (кілька
  хвилин) у пікові періоди — це нормально для безкоштовного тарифу.
- Щоб додати новий тиждень постів, просто попросіть мене — згенерую
  оновлений `schedule.json`.
